# Best Travel — VS Code Starter

A responsive travel website project inspired by the structure and style of travel websites. This is a new, editable implementation—not a copy of another site's source code or an official booking system.

## Getting started
1. Extract the ZIP file.
2. Open the `Best-travel-vscode` folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension and select **Open with Live Server**.

## Main files
- `index.html` — website text, navigation, packages, sections, and forms.
- `css/style.css` — colours, fonts, layout, and responsive design.
- `turkey.html`, `japan.html`, `india.html`, `nepal.html` — individual destination pages with attractions and suggested accommodation areas.
- `css/destinations.css` — styling for destination pages.
- `js/main.js` — mobile navigation, package search, and demo form interactions.

## Quick edits
- Change colours in `:root` in `css/style.css`.
- Update package names and prices in `index.html`.
- Selecting a country on the home page opens its destination page. Update the country options in `index.html` and the matching filenames in `js/main.js`.
- Replace image URLs from `images.unsplash.com` in the CSS to change images.
- The enquiry form opens an email app using `mailto:`. The newsletter form is a demo and does not save email addresses.
- Images require an internet connection.

## Notes
This website uses sample content, external image links, and publicly displayed contact details. It does not include a backend, user accounts, a database, payments, or a live booking system. Before publishing it as an official website, use only assets you are authorized to use and connect the forms to a secure backend.
